## 四条 miss 说明了什么

- 内部测试的号算不算进去 → 文档写的是「测试账号」
- 同一个人买两次算几个人 → 文档写的是「去重用户数」
- GMV 按什么状态统计 → 文档写的是「成交额」
- 交易额归到哪一天 → 文档写的是「归属到 orders.created_at 的下单日期」

四条全部是**与文档字面零重合的同义表达**。这恰好是引入语义检索的论据，但
它只是一个论据——在真机对照跑出来之前，不能反过来当成"语义检索有效"的证据。

分母只含该主体有权且适用的证据；跨业务空间的文档不进分母，否则权限模型会
被算成检索质量问题。
