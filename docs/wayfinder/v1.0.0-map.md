# v1.0.0 — 别的 Agent 能用但不能替人确认；价值有数；接口冻结；讲得清

## Destination

一个 v1.0.0 tag（及 PyPI 上的 `queryagent 1.0.0`），使：

- Claude Code 这类宿主能通过 MCP 准备和执行查询，但确认只能由人在本地确认页或终端里完成；
- 一套场景评测用数字说明本产品保证的东西：该问必问、数字与独立参照一致、未确认执行为 0、
  跨空间泄露为 0、注入生效为 0；
- CLI、配置、映射格式、退出码、库接口与 MCP 工具 schema 进入语义化版本号契约，由快照测试
  钉住；
- 维护者能对照真实代码独立讲清 flow 的调用链，并经过两轮模拟面试检验。

完整方案见 [v1.0.0 技术方案](../specs/v1.0-integration-eval-release.md)。

## Notes

- **本 effort 把 execution 纳入 map**（沿用前几轮做法）。
- 遵循 skills：`tdd`、`code-review`。
- **铁基线**：v0.9.0 发版时的测试数。任一回退即回滚；回滚点 `v0.9.0`。
- **两件对外且不可逆的事单独确认**：PyPI 上传（账号与 pending publisher 由维护者本人设置）；
  封存 test200 的重跑（只在接口冻结后跑一次，之后不因它改任何东西）。
- 每个提交在提交前全量测试（CI 只测推送的最后一个提交）。
