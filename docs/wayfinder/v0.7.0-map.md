# v0.7.0 — 问的是哪段时间，SQL 就算哪段时间

## Destination

一个 v0.7.0 tag，使 `queryagent flow` 的结果行不再需要为时间窗口免责：问题里的时间
表述被换算成绝对日期区间、写在确认单上、绑定进哈希、编译进 SQL；超出支持形态的明确
拒绝，而不是静默算全量。
