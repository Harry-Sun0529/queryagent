# v0.8.0 — 结果说清覆盖了什么、按什么分、文档依据是否真的执行了

## Destination

一个 v0.8.0 tag，使 `queryagent flow` 的结果：

- 说得出库中最新记录是哪天，区间没被数据覆盖的部分明说缺了哪几天；
- 能按天 / 周 / 月或维护者声明的维度分组，每一组都与独立参照一致；
- 统计区间的日期以绑定参数进入查询，而不是拼进 SQL 文本；
- 文档依据与执行的口径互相核对：一致的计入执行口径，不一致的点名，文档依据能经由维护者
  映射选定要执行的口径。

完整方案见 [切片 1C-2 技术方案](../specs/workflow-slice-1c2-2026-09.md)。
