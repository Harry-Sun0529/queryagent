# v0.4.0 — 统计功效、错误分类与数字可信度

## Destination

一个 v0.4.0 tag（**暂不推送**），使这个项目的评测数字**在统计上站得住**、
版本间的数字落差**有定量归因**，并补齐上一轮审计暴露的两类鲁棒性缺口
（长任务中途失败丢结果、错误分类粒度不足）。

## Notes

- **本 effort 把 execution 纳入 map**（覆盖 wayfinder 的 plan-don't-do
  默认值）：路线已在 6 轮 grilling 中厘清，tickets 承载可执行工作。
- 遵循 skills：`tdd`（预声明 seam、红→绿、一次一个纵切）、`code-review`。
- **铁基线**：自建集 首次 11-14/18 · 自修正后 17-18/18 · 追问 4/4。
  任一回退即回滚该改动。
- **统计纪律（本轮的核心认知）**：同一批题的前后对比是**配对设计**，
  用 McNemar，需 57-114 题；跨集合比较（dev 增幅 vs test 增幅）才需
  1089 题/组。此前误用独立样本公式，把前者高估了 2-4 倍。
- **锚点纪律（修订）**：规则表述从「每版本只跑一次」改为
  **「永不因 test 结果改动系统」**——前者是手段，后者才是目的。
- 唯一可用模型：DeepSeek（`deepseek-v4-flash` / `deepseek-v4-pro`）；
  `deepseek-chat` 别名 = v4-flash 关闭思考模式，用于复现 v0.2.0 条件。
