# v0.5.0 — 让声明与证据对齐

## Destination

一个 v0.5.0 tag，使这个项目**README 里的每一句声明都有对应证据**，并把
评测里统计力最弱的两个指标补到能说话的样本量。四轮审计后遗留的短板清单
清零（或明确记为 out of scope）。

## Notes

- **本 effort 把 execution 纳入 map**（覆盖 plan-don't-do 默认值）。
- 遵循 skills：`tdd`（预声明 seam、红→绿、一次一个纵切）、`code-review`。
- **铁基线**：自建集 自修正后 ≥17/18 · 追问全对。任一回退即回滚。
- **本轮的指导教训**（来自 v0.4.0 推送后 CI 变红）：**本地绿 ≠ CI 绿 ≠
  真的能用**。任何"我们支持 X"的声明，必须指出证据在哪；拿不到证据时，
  改声明，而不是留着让读者默认。
- 唯一可用模型：DeepSeek。Anthropic 无 key，因此 A2 的终点是**诚实标注**
  而非"验证通过"。
